== 内容

穹苍宇宙（Rakia Verse）是一个世界构建项目，设定在一个平坦、有限的世界之上，头顶是无限的天穹。其名称源自希伯来语 רקיע（raqia），意为“苍穹”。该设定包含多个智慧种族、多样的魔法体系，以及基于艾什尔里偶因论的形而上学。
